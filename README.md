# 🏨 Hostel One – Your Hostel, One App

Hostel One is a hostel management web application designed to make hostel activities easier for students and wardens.

## ✨ Features

- 👨‍🎓 Student Dashboard
- 🛡️ Warden/Admin Dashboard
- 📢 Hostel Notices
- 📝 Complaint Management
- 🚪 Outpass Requests
- 📅 Leave Requests
- 🍽️ Mess Menu
- 🔐 Login Interface

## 🛠️ Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML
- CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/vikashkrtiwari/Hostel-One.git
cd Hostel-One
```

### 2. Start the Backend

```bash
cd backend
npm install
node server.js
```

Configure the required environment variables in your backend `.env` file before starting the server.

### 3. Start the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.

## 🎯 Project Goal

The goal of Hostel One is to provide a single platform for managing common hostel activities and improving communication between students and wardens.
